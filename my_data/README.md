# my_data (private)

Everything in this folder except this README is ignored by git.
`job-hunt-setup` creates your files here:

- `profile.md`: your career profile (from `config/profile.template.md`)
- `preferences.yaml`: platforms, roles, locations, salary, approval and consent policy
- `form_answers.md`: standard answers for application forms
- `outreach_style.md`: how your outreach drafts should sound
- `applied_log.json`: every job handled
- `cv_review.md`: CV review history (scores per stage, passing and dropped tracks, facts supplied)
- `.private_terms`: optional list of names or words the privacy scanner must block
- `cv/`: your CV file(s)
- `generated/`: tailored CVs, cover letters, tracker workbook, review packs
- `logs/`: run notes
